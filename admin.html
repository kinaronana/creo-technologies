Connect your GitHub account

The website is stored in GitHub. To securely publish edits, create a fine-grained personal access token limited to this repository with Contents: Read and write permission. Your token stays in this browser tab only and is cleared when the tab session ends.

Create a token in GitHub token settings. Select only kinaronana/creo-technologies and grant repository Contents read/write.

Website wording editor

Choose a page, then edit any text shown on that page. Save publishes the changes to the live site after your hosting platform rebuilds it.

Select a page to load its wording.

Service pricing

Set a price for each service. Leave the amount empty to display the note instead (for example, “Contact us for pricing” or “Request a quote”). Prices appear on the homepage service cards and each service page.

Security note: This admin page does not contain a password or embedded GitHub secret. Anyone who wants to publish changes must supply their own authorized repository token. Do not share your token. Revoke it in GitHub settings if it is ever exposed.
